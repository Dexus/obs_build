# caddy2 — OBS package: Caddy with the rate-limit module

Builds [Caddy](https://caddyserver.com) 2.10.x with
[mholt/caddy-ratelimit](https://github.com/mholt/caddy-ratelimit)
(the `rate_limit` directive) compiled in, for **openSUSE SLE/Leap-style
and Fedora/RHEL-style** RPM targets on the
[OpenBuildService](https://build.opensuse.org).

Because OBS build workers have no network access, the package is built from a
small **wrapper module** (`src/`) — the same trick `xcaddy` uses: a `main.go`
that calls Caddy's own `cmd.Main()` and blank-imports the plugin. A `go_modules`
source service vendors all dependencies server-side into `vendor.tar.gz`.

## Layout

| File | Purpose |
|---|---|
| `src/main.go` | Wrapper module: Caddy + plugin imports. Add more plugins here. |
| `src/go.mod`, `src/go.sum` | Pinned dependency set (generated by `update-sources.sh`). |
| `caddy2.spec` | Cross-distro RPM spec (SUSE/Fedora conditionals). |
| `_service` | `go_modules` service, regenerates `vendor.tar.gz` on the server. |
| `update-sources.sh` | Regenerates tarballs + `go.sum`, syncs spec version. |
| `caddy.service`, `Caddyfile` | systemd unit and config skeleton (RPM sources). |
| `caddy2-<ver>.tar.gz`, `vendor.tar.gz` | Generated; commit both via `osc`. |

## Prerequisites

- `osc` (not installed on this machine yet): `zypper install osc` / `dnf install osc`
- `go >= 1.25` only for running `update-sources.sh` (present: go1.26.9)
- Caddy 2.10.x needs **Go ≥ 1.25** — only add repositories to the OBS project
  that can satisfy `golang(API) >= 1.25` (SUSE) / `golang >= 1.25` (Fedora).
  Older targets (SLE 15 SP6, Leap 15.6) cannot build 2.10.x; pin
  `CADDY_VERSION=2.9.1` instead (needs Go ≥ 1.22.3) if you must support them.

## First upload to OBS

```bash
osc checkout home:<youruser>          # your home project (or any project)
mkdir -p "home:<youruser>/caddy2"
cp caddy2.spec _service caddy.service Caddyfile \
   caddy2-*.tar.gz vendor.tar.gz "home:<youruser>/caddy2/"
cd "home:<youruser>/caddy2"
osc addremove
osc commit
```

On commit, the `go_modules` service regenerates `vendor.tar.gz` server-side
(`mode="serveronly"` — no local Go needed just to commit). Then add build
repositories to the project (web UI, or `osc meta -e prj <project>`) and watch
the result at https://build.opensuse.org.

Verify the plugin on an installed system:

```bash
caddy version          # reports "...+ratelimit"
caddy list-modules | grep rate_limit
```

## Updating versions

```bash
CADDY_VERSION=2.10.2 ./update-sources.sh        # bump Caddy
RATELIMIT_REF=<commit> ./update-sources.sh      # pin rate-limit (only stale tags
                                                 # upstream — v0.1.0; master is current)
./update-sources.sh                             # refresh both to defaults
osc addremove && osc commit
```

## Adding more plugins

Add a blank import to `src/main.go`, e.g.
`_ "github.com/caddy-dns/cloudflare"`, then run `./update-sources.sh` and
commit.

## Troubleshooting

- **`nothing provides golang(API) >= 1.25`** — the repository's Go is too old
  for Caddy 2.10.x; drop that repo or downgrade `CADDY_VERSION` (see above).
- **`vendor.tar.gz` missing after commit** — check the package's *Services*
  tab on OBS; you can also regenerate locally with `osc service run go_modules`
  (needs local Go) and commit the result.
- **Spec edit fails on `go build` with "missing go.sum entry"** — the wrapper
  tarball's `go.sum` is stale; re-run `./update-sources.sh`.
